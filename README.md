# Day 9: Calculator

This folder contains:

- `day9_calculator_example.py` uses fixed values to demonstrate arithmetic operators, as shown in the lesson notes.
- `Calculator.py` is an interactive calculator that accepts mathematical expressions.

## Run the fixed-value example

```bash
python day9_calculator_example.py
```

## Run the interactive calculator

```bash
python Calculator.py
```

Type `exit` to close the interactive calculator.
